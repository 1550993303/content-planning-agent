# 合成资料与规则

唯一可执行数据源位于 [`src/content_planner/data/catalog.json`](../src/content_planner/data/catalog.json)。将其作为包资源，是为了让安装后的 CLI 能在任意目录读取相同资料，避免依赖工作目录。这里不维护第二份可漂移的数据副本。

| 项目 | 模拟费用 | 串行耗时（分钟） |
| --- | ---: | ---: |
| A01 毕业季精品校园镜头 | 4 | 30 |
| A02 毕业季基础图文素材 | 2 | 15 |
| A03 咖啡店基础素材 | 2 | 15 |
| premium 脚本 | 8 | 90 |
| basic 脚本 | 6 | 30 |

素材准备费用按所选不重复素材逐项相加，脚本费用计算一次，二者之和为候选方案总费用；耗时同样按串行相加。检索、估算、保存本身为零模拟费用；真实模型账单独立。

业务规则：

1. 素材必须先通过检索取得，禁止模型编造 ID。
2. 预算、截止时间为硬要求；只有费用不超过预算且预计完成时间不晚于截止时间的估算才可继续生成和保存。
3. 精品偏好是软偏好。可以在观察约束失败后自主降级，不允许程序擅自改变用户预算或截止时间。
4. 脚本只能由成功估算生成，保存必须引用对应估算和脚本。
5. 所有资料均为合成；不存在真实授权、采购、营销效果或发布行为。
